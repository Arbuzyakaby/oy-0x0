### Кнопки «0» и «1»
- Короткое, долгое и двойное нажатие — любое действие: фонарь, камера, OY Assist, диктофон, призрачный профиль, сигнальный фонарь, бесшумный режим и т. д.
- **Аппаратный режим:** любую кнопку можно назначить на Null Chip — тогда нажатие физически обесточивает выбранное (камеры, микрофоны, связь, геолокация). Рядом с кнопкой — индикатор.
- Обе кнопки одновременно на 2 секунды — «Всё выключить»: камеры, микрофоны, связь и геолокация без питания.
- Переназначить кнопку в аппаратном режиме можно только после отпечатка.
- Аппаратный режим сильнее Claw 2.0.

## 2. Страница `/0x1/`
Hero → дизайн (новая форма) → камеры → кнопки «0» и «1» (3D + интерактивное назначение) → Claw 2.0 →
экран и «Антиблик 2» → производительность → батарея → разбор по слоям → цвета → OY OS 2 →
«Коротко о главном» → конфигуратор и характеристики → финал.

## 3. Сайт
- Шапка всех страниц: 0X0 · 0X1 · 0X0 Pro · OY OS · Сравнить.
- Витрина: три телефона, три карточки, мини-сравнение на три колонки.
- Сравнение: три колонки (0X0, 0X1, 0X0 Pro); фильтр «только различия» скрывает строки, где все три совпадают.
- `COMPARE` в `products.js`: `[раздел, параметр, 0X0, 0X1, Pro, key]`.

## 4. 3D-модель
`blender/build_oy0x1.py` → `models/oy0x1.glb`. Ноды: `Frame`, `Antennas`, `Body` (матовое стекло спинки),
`Glass`, `Screen`, `PunchHole`, `CamIsland` (рамка острова), `CamPlate`, `CameraModules`, `Periscope`, `Flash`,
`SignalLight`, `TopDetails`, `KeySlots`, `Key_1..2` + `KeyIndicator_1..2`, `PowerButton`, `VolumeRocker`, `BottomDetails`.
Процедурная резервная модель с теми же именами; разлёт по слоям с Null Chip.
