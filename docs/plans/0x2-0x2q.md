## 2. OY 0X2 (наследник 0X1)

| | |
|---|---|
| Процессор | Qualcomm Snapdragon 8s Gen 4 |
| Память | **11/256 · 17/512 · 21/1024** (LPDDR5X + UFS 4.0). На сайте отдельный раздел «Числа, которых нет ни у кого»: 11, 17, 21 — все простые |
| Чип безопасности | **Tesseract**: свой процессор, 84 ГБ, аккумулятор 1000 мАч, сетка от вскрытия. Сильнее Citadel 2 (64 ГБ, 600 мАч) |
| Основная | 50 МП, 1/1,5", f/1.6, OIS (у 0X1 было 60 МП, 1/1,3") |
| Сверхширокая | 32 МП, 118°, макро (было 50 МП, 120°) |
| Телевик | 50 МП, перископ 3×, f/3.0, OIS, сенсор меньше |
| Фронтальные | 24 МП квадратная + **12 МП сверхширокая**, всего **5 камер** |
| Корпус | дизайн 0X1, **7,9 мм, 192 г** (было 8,9 мм, 214 г), испарительная камера |
| Аккумулятор | 7300 мАч, кремний-углеродный, ячейки плотнее |
| Зарядка | XMagnum (магнитная), шайба продаётся отдельно |
| Связь | **NFC** через Tesseract («Кошелёк»), первые OY с NFC |
| Цвета | **Медовый · Листовой Зелёный · Цветочный Розовый** |
| Кнопки | «0» и «1», как у 0X1 |
| Система | OY OS 3, 8 лет обновлений |

**Функции Tesseract.** Перешли от Citadel 2:
- «Сторож»
- «Последнее слово»
- «Тревожный палец»

Новые:
- **«Кошелёк»**: NFC-оплата и ключи живут только в чипе.
- **«Двойник»**: по отдельному PIN открывается фальшивая правдоподобная система.
- **«Свидетель»**: журнал аппаратных событий, подписанный чипом.
- **«Карантин»**: любой USB- или NFC-предмет сначала проверяет чип.
- **«Тихий час»**: радио и датчики отключаются по расписанию, решение принимает чип.
- **«Мёртвая рука»**: если владелец N дней не подтверждал себя, ключи уничтожаются и уходит письмо доверенному контакту.

## 4. Загрузчик (оба телефона)

Загрузчик заблокирован намертво, снять блокировку **нельзя никак**: ни в сервисе OY, ни самой OY. При попытке разблокировки чип включает девять ступеней защиты:

1. Проверка подписи
2. PIN владельца
3. Пароль чипа
4. Биометрия
5. Задержка 72 часа
6. Повторное подтверждение
7. Проверка сетки от вскрытия
8. Уничтожение ключей пользователя
9. Запись в «Свидетель»

Если все девять пройдены, чип **аппаратно обесточивает** камеры, датчики, микрофоны и динамики. Это необратимо.

## 5. OY OS 3

**OY Assist 3**
- агент, который сам работает в приложениях;
- память на устройстве: список «что я о тебе знаю» с удалением любого пункта;
- понимает, что на экране;
- расшифровка встреч с разбивкой по участникам;
- «Сводка дня»;
- распознавание синтезированного голоса и сгенерированных фото.

**Приватность**
- отчёт за неделю;
- «Отравленные данные»;
- одноразовые адреса и номера;
- разрешения с таймером;
- «Стеклянная стена»;
- случайный MAC-адрес;
- буфер обмена с замком;
- запрет записи экрана.

**Безопасность**
- «Двойник», «Кошелёк», «Свидетель», «Мёртвая рука»;
- «Граница»: режим для поездок через паспортный контроль;
- «Чужие руки»: блокировка, если телефон выхватили;
- «Зеркало»: защита от взгляда через плечо;
- passkeys хранятся в чипе;
- предупреждение о поддельной вышке и подозрительном Wi-Fi;
- загрузчик на 9 ступеней.

**Связь**
- ассистент отвечает на звонки с незнакомых номеров;
- офлайн-перевод на 40 языков;
- mesh-сообщения без сети;
- спутниковые SMS прямо в «Сообщениях»;
- отложенные и отзываемые сообщения.

**Камера и модули**
- менеджер модулей;
- тепловизорный режим;
- «Чистое фото»;
- пульт для «Луча»;
- видео с подписью чипа.

**Удобство**
- разблокировка по NFC-метке;
- «Тихие обои»;
- режимы, которые считаются на устройстве;
- рабочий стол на внешнем мониторе;
- режим одной руки 2;
- «Детский телефон».

**Батарея**
- умная зарядка 3;
- профиль испарительной камеры;
- аварийный режим: до 5 дней на 5 % заряда.

**Открытость**
- воспроизводимая сборка 2;
- открытые логи чипа;
- 8 лет обновлений.

Интерактивные демо на `/os/`:
- агент в приложениях;
- «Двойник»;
- «Граница»;
- mesh-сообщения;
- ответ на звонок с незнакомого номера.
