## Что умеет сайт

- **Одна модель на всю страницу.** Телефон отрисован в Three.js на fixed-canvas за контентом. Поза, механика и подсветка меняются от прокрутки.
- **Механика двигается от скролла.** Шторка закрывает камеры, kill switches выключаются по очереди, фонарь загорается, и луч уходит вдаль. На Pro модель разлетается, чтобы показать Citadel, и подсвечивает антенны Claw.
- **Цвет меняет всё.** Смена корпуса за 0,7 с перекрашивает и модель, и акценты страницы. Выбор запоминается.
- **Приёмы Apple.** Закреплённые секции и scrub на GSAP ScrollTrigger, плавная прокрутка Lenis, карусель с прогрессом на точке и паузой, абзац, который загорается по словам, градиентные заголовки, подменю-таблетки с подсветкой раздела.
- **Демо вместо картинок.** Журнал доступа, песочница, разрешения на время, приблизительная геолокация, SOS фонарём азбукой Морзе. На странице OY OS: ассистент, карта запросов, призрачный профиль, PIN-клавиатура и проверка хеша.
- **Сноски, как у Apple.** Важные цифры (яркость, ёмкость, время зарядки, защита от воды, 7 лет обновлений) помечены цифрой, расшифровка — внизу страницы со ссылкой обратно к тексту. Сноски переживают анимацию заголовков по строкам.
- **Конфигураторы.** Память меняет цену в долларах и евро («Европа — скоро»). «Средиземноморский Мрамор» доступен только в старших версиях Pro и с наценкой.
- **Подколы.** Ровно столько, сколько нужно. «Удалить аккаунт — одна кнопка. Шутка. Аккаунта у нас нет».

## Запуск

Сборщик не нужен: это чистые HTML, CSS и ES-модули. Нужен только локальный сервер, потому что браузер не загружает GLB по `file://`.

```bash
git clone https://github.com/Arbuzyakaby/oy-0x0.git
cd oy-0x0
npx serve .
```

Вместо `npx serve` подойдёт `python -m http.server 8000`. Витрина откроется на корне, оттуда ссылки на все страницы.

| Параметр адреса | Что делает |
|---|---|
| `?fallback` | Показывает процедурную модель, как при ошибке загрузки GLB |
| `?debug` | Открывает в консоли `window.__oy`: состояние сцены и ScrollTrigger |

js/data/products.js      цены, цвета и сравнение — единственный источник цифр
js/pages/                хореография страниц: base.js (0X0), 0x1.js, 0x1q.js, pro.js, home.js, compare.js, os.js

**Хореография.** Поза телефона, положение шторки, ползунков и яркость фонаря задаются ключевыми кадрами, привязанными к ScrollTrigger каждой секции. На каждом тике прокрутка превращается в целевое состояние, а сцена плавно его догоняет. Поэтому модель всегда в правильной позе, даже если прыгнуть по якорю в середину страницы. HTML-подписи берут значения из того же источника и не расходятся с 3D.

**Модели собраны кодом** в Blender, без ручного моделирования:

```bash
blender -b -P blender/build_oy0x0.py       # OY 0X0 → models/oy0x0.glb
blender -b -P blender/build_oy0x1.py       # OY 0X1 → models/oy0x1.glb
blender -b -P blender/build_oy0x1q.py      # OY 0X1Q → models/oy0x1q.glb, модуль камеры — отдельная нода Module
blender -b -P blender/build_oy0x0_pro.py   # OY 0X0 Pro, общие хелперы в blender/oy_common.py
blender -b -P blender/build_accessories.py # аксессуары: Cycles-рендеры в img/accessories/*.png (--only glass,puck --samples 64)
blender -b -P blender/preview_render.py -- models/oy0x0.glb preview   # превью, --closed для закрытой шторки
```

Подвижные части вынесены в отдельные ноды (`Shutter`, `Switch_1..3`, `Key_1..2`, `Module`, `SignalLight`, `Screen`), материалы (`Body`, `Frame`, `SignalLightGlow` и другие) названы так, чтобы сайт мог к ним обращаться. Проверено на Blender 5.2, рассчитано на 4.x и 5.x.

**Если GLB не загрузился**, модель строится прямо в браузере, с теми же именами деталей. Сайт работает всегда.

**OY OS 2 без 3D.** Телефоны на этой странице нарисованы на CSS, демо написаны на чистом JS. Страница грузит только GSAP и Lenis.

## Приватность

Сайт телефона без Google сам тоже ничего не отдаёт Google:

- никакой аналитики, трекеров, cookies и сторонних эмбедов;
- внешние запросы только к `cdn.jsdelivr.net` (библиотеки), шрифты лежат на самом сайте;
- Content Security Policy на каждой странице разрешает только этот домен;
- в `localStorage` хранится только выбранный цвет корпуса.

Откройте вкладку «Сеть» в DevTools и проверьте сами.

## Доступность и производительность

- Семантическая разметка, подписи для иконок, видимый фокус, контраст текста не ниже AA.
- Переключатели, конфигураторы и все демо работают с клавиатуры.
- `prefers-reduced-motion`: без закреплений, плавной прокрутки и параллакса, только простые появления.
- `devicePixelRatio` ограничен двумя. Рендер останавливается, когда 3D-секции не видны или вкладка скрыта.
- Работает на экранах от 360 px.

## Тесты

```bash
npm test
```

Юнит-тесты проверяют ключевые кадры хореографии и данные моделей: цены, цвета, наценку за мрамор и совпадение сравнения с конфигурациями.
