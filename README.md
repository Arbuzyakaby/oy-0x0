## Что умеет сайт

- **Одна модель на всю страницу.** Телефон отрисован в Three.js на fixed-canvas за контентом. Поза, механика и подсветка меняются от прокрутки.
- **Механика двигается от скролла.** Шторка закрывает камеры, kill switches выключаются по очереди, фонарь загорается, и луч уходит вдаль. На Pro и 0X2 модель разлетается, чтобы показать чип безопасности. У 0X2Q модуль выезжает из корпуса, прячется за шторку и меняется на другой.
- **Подменю модели, как у Apple.** Под общей шапкой — название модели, разделы, цвет и «Купить». При прокрутке шапка уезжает, подменю прилипает и подсвечивает текущий раздел, на телефоне раскрывается списком.
- **Цвет меняет всё.** Смена корпуса за 0,7 с перекрашивает и модель, и акценты страницы. Выбор запоминается.
- **Приёмы Apple.** Закреплённые секции и scrub на GSAP ScrollTrigger, плавная прокрутка Lenis, карусель с прогрессом на точке и паузой, абзац, который загорается по словам, градиентные заголовки, подменю-таблетки с подсветкой раздела.
- **Демо вместо картинок.** Журнал доступа, песочница, разрешения на время, приблизительная геолокация, SOS фонарём азбукой Морзе. На странице OY OS: вход в OY ID, место в 0X Cloud, ассистент с лимитом запросов, стеклянная линза, сервисы Google, стили главного экрана, «Воспоминания», обновление ночью, призрачный профиль и PIN-клавиатура.
- **Сноски, как у Apple.** Важные цифры (яркость, ёмкость, время зарядки, защита от воды, 7 лет обновлений) помечены цифрой, расшифровка — внизу страницы со ссылкой обратно к тексту. Сноски переживают анимацию заголовков по строкам.
- **Конфигураторы.** Память меняет цену в долларах и евро («Европа — скоро»). У снятого с продажи 0X0 Pro конфигуратора нет — только ссылка на преемника. Рядом с долларами и евро — юани у всех моделей в продаже (у 0X1 Essential, 0X1, 0X1Q, 0X1 Pro, 0X2 Essential, 0X0, 0X2, 0X2Q и eXtream Y1 — отдельной строкой, у 0X2 Pro, 0X Moth и 0X Nova — третьей кнопкой валюты, общей для страниц). У снятого 0X0 Pro юаней нет.
- **Подколы.** Ровно столько, сколько нужно. «Удалить аккаунт — одна кнопка. Шутка. Аккаунта у нас нет».

## Запуск

Сборщик не нужен: это чистые HTML, CSS и ES-модули. Нужен только локальный сервер, потому что браузер не загружает GLB по `file://`.

```bash
git clone https://github.com/Arbuzyakaby/oy-0x0.git
cd oy-0x0
npx serve .
```

Вместо `npx serve` подойдёт `python -m http.server 8000`. Витрина откроется на корне, оттуда ссылки на все страницы.

**Перед выкладкой — `npm run stamp`.** Cloudflare отдаёт JS и CSS с кешем на 4 часа, и без версий браузер может взять новый HTML со старым модулем. Скрипт `tools/stamp.mjs` ставит `?v=<хеш содержимого>` всем CSS, точкам входа и GLB, а внутренние импорты модулей подменяет через import map. `npm test` падает, если версии устарели.

| Параметр адреса | Что делает |
|---|---|
| `?fallback` | Показывает процедурную модель, как при ошибке загрузки GLB |
| `?debug` | Открывает в консоли `window.__oy`: состояние сцены и ScrollTrigger |

**Хореография.** Поза телефона, положение шторки, ползунков и яркость фонаря задаются ключевыми кадрами, привязанными к ScrollTrigger каждой секции. На каждом тике прокрутка превращается в целевое состояние, а сцена плавно его догоняет. Поэтому модель всегда в правильной позе, даже если прыгнуть по якорю в середину страницы. HTML-подписи берут значения из того же источника и не расходятся с 3D.

**Модели собраны кодом** в Blender, без ручного моделирования:

blender -b -P blender/build_oy0x1e.py      # OY 0X1 Essential → models/oy0x1e.glb
blender -b -P blender/build_oy0x2e.py      # OY 0X2 Essential → models/oy0x2e.glb, острые углы, шторка Shutter и Switch_1, Switch_2

## Приватность

Сайт телефона без Google сам тоже ничего не отдаёт Google:

- никакой аналитики, трекеров, cookies и сторонних эмбедов;
- внешние запросы только к `cdn.jsdelivr.net` (библиотеки), шрифты лежат на самом сайте;
- Content Security Policy на каждой странице разрешает только этот домен;
- в `localStorage` хранятся только выбранный цвет корпуса и, на страницах 0X2 Pro, 0X Moth и 0X Nova, валюта цен (общая для всех); на странице Nova — ещё нарисованные пером созвездия.

Откройте вкладку «Сеть» в DevTools и проверьте сами.

## Доступность и производительность

- Семантическая разметка, подписи для иконок, видимый фокус, контраст текста не ниже AA.
- Переключатели, конфигураторы и все демо работают с клавиатуры.
- `prefers-reduced-motion`: без закреплений, плавной прокрутки и параллакса, только простые появления.
- `devicePixelRatio` ограничен двумя. Рендер останавливается, когда 3D-секции не видны или вкладка скрыта.
- Работает на экранах от 360 px.

## Тесты

```bash
npm test
```

Юнит-тесты проверяют ключевые кадры хореографии и данные моделей: цены, цвета, лестницу цен, преемников снятых моделей, наценку за мрамор и совпадение сравнения с конфигурациями. Тесты страниц следят, чтобы import map каждой страницы был валидным JSON, все подключённые файлы существовали, а в шапке были только модели в продаже. Сценарии в `tests/e2e/` запускаются через Playwright: регрессия страницы 0X0, скриншоты Pro на десктопе и телефоне, скриншоты 0X1, 0X1Q, 0X1 Pro, 0X1 Essential, 0X2 Essential, 0X2, 0X2Q, 0X2 Pro и 0X Moth с превью ссылок и витрины. Сценарий 0X2 Pro заодно проверяет переход блоками, `#layer-5`, валюту после перезагрузки, блок под пальцем и страницу без JS; сценарий Moth — лист сгиба посреди перехода, `#fold-4`, гирлянду, полароиды, валюту и страницу без JS; сценарий Nova — все главы на десктопе и телефоне, зум до Mono, созвездия после перезагрузки, подпись снимка, блокировку игры и страницу без JS; сценарий eXtream — все уровни Y1 и хаб на десктопе и телефоне, курки с клавиатуры, пасхалку, стресс-тест без вентиляторов, ¥ после перезагрузки и страницу без модуля; сценарий Fyr — «Перехват» по `x0` на главной, Nova, 404 и eXtream и по пяти касаниям щита на телефоне, переход между страницами, «Вернуть OY», все главы `/fyr/`, «Сейф» и страницу без JS. Отдельный тест следит, чтобы для Moth на сайте было только слово «мотылёк», и чтобы у каждого аксессуара был рендер. Для eXtream — что на сайте нет ни слова о том, что прячет Erbium, ни имени партнёра по коллабу, а в шапке каждой страницы OY есть ссылка на суббренд.
